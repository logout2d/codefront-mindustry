# Licensing Notes

Status: preliminary project note, not legal advice.

Mindustry's official source repository is published under the GNU GPL v3. The Codefront repository currently does **not** declare its own project license yet.

Before distributing Codefront binaries publicly, choose a license deliberately and verify GPL compatibility/obligations for a Java mod linked against Mindustry APIs and for any copied/adapted code or assets.

Practical default for an open-source Mindustry-derived project is to consider a GPLv3-compatible license, but this decision should be explicit rather than accidental.

Do not copy Mindustry art/audio/assets into this repository unless their redistribution terms are verified separately.
